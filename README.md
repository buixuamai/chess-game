# Chess Game

A beautiful 2-player chess game that runs in your browser. Deploy easily to GitHub Pages!

## Features

- ✅ Full chess rules (castling, en passant, pawn promotion)
- ✅ Move history display
- ✅ Undo functionality
- ✅ Check and checkmate detection
- ✅ Beautiful responsive design

## How to Play

1. Click and drag pieces to move
2. White moves first
3. Click "New Game" to restart
4. Click "Undo" to take back moves

## Quick Start

### Option 1: Run Locally

1. Clone this repository
2. Open `index.html` in your browser

### Option 2: Deploy to GitHub Pages

1. Create a new repository on GitHub
2. Push this code to your repository
3. Go to **Settings** → **Pages**
4. Select the `main` branch as the source
5. Save and wait for deployment
6. Your game will be live at: `https://yourusername.github.io/repo-name`

## Technologies Used

- [Chess.js](https://github.com/jhlywa/chess.js) - Chess move validation
- [Chessboard.js](https://chessboardjs.com/) - Chess board UI
